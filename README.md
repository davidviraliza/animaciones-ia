# Animaciones con IA · plugin gratuito para Claude Code

Haz videos verticales animados (9:16) con Claude Code y herramientas gratis en tu PC, con el método del tutorial del canal **Animaciones con IA**: analiza un enlace, propone 3 temas, escribe el guion con fuentes, narra con tu voz clonada (o una voz ya hecha), propone el estilo en 3 cuadros, revisa cuadro por cuadro y le pone música original.

**Necesitas:** Windows 10/11, Claude Pro o superior (app de Claude, pestaña **Code**) y ~12 GB libres. Para clonar tu voz: tarjeta NVIDIA de 6 GB o más.

## Instalar (1 minuto)
1. Abre la app de Claude, pestaña **Code**, y elige cualquier carpeta (por ejemplo `Documentos`).
2. Copia y pega este mensaje:
   ```
   Instala el plugin animaciones-ia: corre «claude plugin marketplace add davidviraliza/animaciones-ia» y luego «claude plugin install animaciones-ia@animaciones-con-ia». Avísame en español cuando termine.
   ```
3. Cuando Claude diga que terminó, cierra y vuelve a abrir la app.
4. Crea una carpeta para tu video, ábrela en la pestaña Code y escribe `/animaciones-ia:preparar`.

Después: `/animaciones-ia:video <enlace de un video que te guste, o tu idea>`.
